# WINGS AI Frontend

React + Vite + JavaScript frontend for the WINGS AI Platform.

## Run

```bash
cp .env.example .env
npm install
npm run dev
```

Open http://localhost:5173

Backend defaults to http://localhost:8000/api/v1.

The AI Console and document ingestion use the real WINGS backend APIs. Dashboard and some operational screens contain presentation scaffolding where exact backend list endpoints were not established in the conversation.
